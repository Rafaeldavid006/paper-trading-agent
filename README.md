# מערכת מחקר אירועים — אביעד

גרסת פיתוח מקומית עם ממשק מחקר בעברית. אינה מותקנת באתר הקיים ואינה מבצעת עסקאות. קרא גם BLUEPRINT.he.md ליעד ולפערים.

## הפעלה למפתח

מתיקיית החבילה:

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
# מאחורי HTTPS:
gunicorn --workers 1 --threads 4 --timeout 120 --bind 0.0.0.0:8000 wsgi:app
```

הגדר DASHBOARD_PASSWORD באורך 20 תווים לפחות, FLASK_SECRET_KEY אקראי וקבוע ו־EVENT_DB לנתיב מוחלט בתיקייה קיימת על אחסון מתמשך. אחרת ברירת המחדל היא events.db מקומי. PERSISTENT_STORAGE_CONFIRMED=true הוא אישור מפעיל בלבד, לא בדיקת אחסון. אין לשמור מפתחות או מסד נתונים במאגר ציבורי.

הממשק משתמש ב־Basic Auth, הגנת CSRF ו־escaping. לפני חשיפה ציבורית יש להגדיר בשירות הגבלת ניסיונות כניסה; אין במימוש MFA או הגבלת קצב אימות. החבילה אינה כוללת את דף חשבון Alpaca מהגרסה הישנה ולכן אינה תחליף ישיר להתקנה הקיימת.

## רכיבים מחוברים

- monitor.py שומר חדשות לפי רשימת מעקב. איסוף מהממשק מתרחש רק בלחיצה; ניטור מתמשך דורש תהליך נפרד.
- event_core.py שומר אירועים, תיקונים, זמנים, ציפיות מוקדמות ובריאות מקורות.
- event_types.py כולל 12 משפחות אירועים ומצב לא מסווג. ניתן לשלב סוגים; הסיווג קלט מפורש ולא אימות אוטומטי.
- relationships.py שומר קשרים עם מקור, קטע ראיה, זמני פרסום וקליטה ותוקף. סוגי קשרים כוללים ספקים, לקוחות, מתחרים, ריבית, מטבע, אזורים, רגולציה ולוגיסטיקה.
- pipeline.py מחבר אירוע למחקר ולביקורת AI לפי בקשה. חבילת המקורות והתוצאה נשמרות; תיקון לאירוע מסמן מחקר קודם כמיושן.
- webapp.py מציג אירועים, חיבורים, מחקרים ותוצאות, ומאפשר להזין קשר וראיה.

המערכת אינה קוראת קישור שהוזן. קטע המקור שהמפעיל מספק נשמר כקלט לא מאומת; האירוע במחקר הקשרים נשאר לא מאומת. קשר עסקי אינו מוכיח רווח או תגובת מחיר.

## חיבורים

לחדשות: ALPACA_API_KEY, ALPACA_SECRET_KEY ו־WATCHLIST, לדוגמה SPY,QQQ. עד 20 סימולים. תהליך ניטור נפרד:

```bash
python monitor.py --db /absolute/persistent/path/events.db --symbols SPY,QQQ --interval 30
```

זה polling ולא streaming. נאספים פריטי 24 השעות האחרונות בעימוד מוגבל; הגעה לגבול מסומנת coverage_incomplete. הממשק מציג הצלחה וניסיון אחרונים; מפתח מוגדר אינו חיבור מאומת. אין פעילות לאחר עצירת התהליך.

ל־AI: OPENAI_API_KEY, OPENAI_MODEL וכן ENABLE_AI_RESEARCH=true. ברירת המחדל כבויה. ניתוח נגיש רק לחבילת מחקר עם קשרים נתמכי מקור. הלקוח משתמש ב־Responses API עם פלט מובנה בעברית; אין גלישה או מחקר רשת עצמאי.

AI_MAX_CALLS_PER_DAY מגביל ניסיונות Pipeline, ברירת מחדל 5 ביום UTC. הספירה נשמרת במסד הנתונים ומשותפת למשתמשים באותו קובץ; גם כישלון נספר. ניסיון שנקטע אינו נשלח אוטומטית שוב. אותו מזהה מחקר לא ינותח פעמיים. מחקר חדש במועד אחר חולק אותה מכסה. זו אינה תקרת חיוב כספית או תקרת שימוש בחשבון כולו. קריאה ישירה ל־analyze עוקפת מכסה זאת; אין להפעילה בלולאה.

## מגבלות

כל תוצאה כוללת order_permission=none. אין ביצועי מסחר. בדיקת הפניות לראיות בודקת מזהים, לא הוכחה סמנטית מלאה. חסרים איסוף ראיות עצמאי, אימות אירועים, התאמת ישויות, סיווג אוטומטי, כיסוי רחב מעבר לרשימת מעקב, נתוני שוק רציפים מאוחדים, מודל החלטה מכויל וביצוע דמו.

הניסוי Store.evaluate נפרד ממחקר הקשרים; הוא דורש ציפיות ומחירים שנשמרו לפני האירוע. backfill אינו יוצר ידיעה מוקדמת. ספי הניסוי אינם מוכחים. טקסט AI אינו אישור עסקה. השאר את מנוע המומנטום הישן כבוי בזמן פיתוח אסטרטגיית האירועים.

## חיפוש אוטומטי ומעבר להפעלה

נוספו discovery.py ו־research_worker.py. כעת ניתן לבקש מחקר אינטרנטי ישירות מאירוע, בלי להזין קשרים ידנית. כלי web_search מחזיר מקורות והפניות; הדוח נשמר ומוצג עם קישורים. מחקר ללא קריאת חיפוש שהושלמה, ללא הפניות, עם הפניה שאינה במלאי המקורות או עם פלט חלקי נכשל. זמני פרסום של המקורות וקשרים מובנים אינם מחולצים כאמת; הדוח אינו מוכנס אוטומטית לגרף ואינו מאשר מסחר. זו יכולת חדשה ולא חיבור חי שנבדק מול חשבון הלקוח.

הגדר ENABLE_WEB_RESEARCH=true כדי לאפשר חיפוש ידני באתר. המכסה AI_MAX_CALLS_PER_DAY משותפת לחיפוש ולביקורת גרף. לכל גרסת אירוע מתבצע לכל היותר ניסיון חיפוש אחד, כולל כישלון או ניתוק; אין ניסיון חוזר אוטומטי. בבקשת חיפוש מוגדרים max_tool_calls=4 ו־max_output_tokens=5000. אין בכך תקרת חיוב כספית. מודל מוגדר חייב לתמוך בכלי; זמינות וגישת החשבון דורשות בדיקה חיה.

להפעלה אוטומטית הגדר גם ENABLE_AUTO_RESEARCH=true. העובד אוסף חדשות וחוקר לכל היותר אירוע אחד בכל מחזור של 60 שניות. רק אירועים שפורסמו ב־15 הדקות האחרונות, שאינם מתוקנים ושטרם נחקרו נבחרים, ורק אם איסוף החדשות האחרון הצליח עם כיסוי מלא. אין קדימות לפי חשיבות או מניעת כפילות סמנטית בין ספקים וסימולים; המכסה מגינה מפני מספר בקשות בלתי מוגבל.

serve.py מפעיל באותו שירות את אתר המחקר ואת העובד האופציונלי, עם אותו קובץ נתונים. פקודת התחלה: `python serve.py`. יש להריץ מתיקיית החבילה. אתר ועובד מופסקים אם אחד התהליכים יוצא. להפעלה אוטומטית נדרשים EVENT_DB מוחלט, PERSISTENT_STORAGE_CONFIRMED=true, שני מפתחות Alpaca, מפתח OpenAI ומודל. FLASK_SECRET_KEY חייב להיות באורך 32 תווים לפחות. פריסה, אחסון מתמשך, השגחת השירות וחשבונות הספקים נדרשים מחוץ לצ׳אט. השירות אינו סוכן מסחר דמו או מסחר אמיתי.

מקורות המימוש: https://developers.openai.com/api/docs/guides/tools-web-search ו־https://developers.openai.com/api/reference/python/resources/responses .

66 בדיקות מקומיות עברו בגרסה זו; בדיקות החיפוש, ה־AI והחדשות מדומות. אין טענה לזמן אמת, לניטור פעיל או לביצועים פיננסיים מוכחים.
